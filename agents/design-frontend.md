# 디자인·프론트엔드
- 목적: 로컬 사용자가 프롬프트를 선택·검토하고 음악을 만들고 들을 수 있는 화면.
- 입력: 사용자 요구, 기존 templates/web 및 static/web, web API.
- Phase 1 담당 파일: outputs/local-dashboard/phase-1/design-frontend.md.
- 조사 범위: 기존 화면과 동작, 카테고리·변형 선택, 프롬프트 편집, 결과 재생·다운로드, 대시보드 구성.
- 산출물: 근거 파일을 포함한 현황, 제안 화면과 상태, 접근성, 이후 구현 소유권 제안.
- 완료 조건: 사실·추정·확인 필요 구분, 필수 사용자 흐름과 오류 상태 명시.
- 제품 파일 수정은 Phase 2 승인 후 별도 배정한다. 루트 AGENTS.md의 승인·보고 규칙을 따른다.
